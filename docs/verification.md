## Ограничение проверки Docker

Полный запуск с настоящим бекендом пока не подтверждён. Команда `docker compose up -d` вне песочницы возвращает HTTP 500 от Docker Desktop при обращении к движку Linux. В журнале Docker состояние `stopped`, признак `hasNoVirtualization: true`. Windows API также возвращает `False` для `PF_VIRT_FIRMWARE_ENABLED`. На компьютере установлен AMD Ryzen 5 5500, WSL 2.6.1.0.

Нужно проверить "SVM Mode" в BIOS/UEFI и доступность виртуализации для Windows. Проверки `healthcheck`, обмен с настоящей базой и сохранение данных в томе можно подтвердить только после запуска движка.

Тестовые ответы использовались только во временном локальном сервере. В приложение и репозиторий они не добавлены.
